# SMART DEMAND FORECASTING AND INVENTORY OPTIMIZATION SYSTEM

## 📌 Project Overview

The Smart Demand Forecasting and Inventory Optimization System is a data-driven solution developed to forecast product demand and support inventory planning using historical retail sales data.

The project combines data preprocessing, exploratory data analysis, feature engineering, machine learning-based demand forecasting, inventory optimization, and Power BI visualization.

## 🎯 Objectives

* Forecast future product demand using historical sales data.
* Analyze sales trends and product-level demand.
* Calculate safety stock and reorder points.
* Identify products requiring urgent reorder.
* Recommend inventory order quantities.
* Provide interactive business insights through Power BI.

## 📦 Inventory Optimization

The inventory optimization component uses:

* Average Daily Demand
* Demand Standard Deviation
* Safety Stock

* Recommended Order Quantity
* Inventory Status

Inventory status categories include:

* Urgent Reorder
